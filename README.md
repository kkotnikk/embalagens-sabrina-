# Embalagens Sabrina

Site institucional estático da Embalagens Sabrina, com categorias de produtos, galeria de fotos, reserva pelo WhatsApp e informações de contato.

## Arquivos

- `index.html`: conteúdo da página.
- `styles.css`: identidade visual, layouts responsivos e animações.
- `app.js`: categorias, filtros e visualização de fotos.
- `assets/`: logo e imagens otimizadas.

## Visualizar localmente

Na pasta do projeto, execute `python -m http.server 8000` e abra `http://localhost:8000`.

## GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)**.
